Репозиторий RSS Reader (Фильтрация новостей)
Описание
RSS Reader (Фильтрация новостей) – это набор консольных утилит на 8 языках программирования для чтения RSS/Atom лент с расширенными возможностями фильтрации. Программа позволяет:

Добавлять и удалять ленты по URL.

Обновлять ленты и отображать новости с возможностью фильтрации по:

Ключевым словам (в заголовке, описании, категориях).

Дате (за последние N дней).

Источнику (название ленты).

Статусу (прочитанные / непрочитанные).

Настраивать фильтры – сохранять их в профиль для автоматического применения при каждом обновлении.

Просматривать новости с цветной подсветкой (темная тема).

Открывать ссылки в браузере.

Экспортировать / импортировать подписки в OPML.

Кэшировать новости для быстрого доступа.

Проект создан как тестовый репозиторий для демонстрации реализации одной задачи на разных языках с акцентом на удобство фильтрации и производительность.

Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Python	Python 3.8+ (стандартные библиотеки)	python rss.py [команда] [аргументы]
JavaScript	Node.js 14+ (без внешних модулей)	node rss.js [команда] [аргументы]

Ruby	Ruby 2.7+ (без гемов)	ruby rss.rb [команда] [аргументы]

Команды
Команда	Описание
add	Добавить ленту (требует --url и --title).
remove	Удалить ленту по --id или --url.
list	Показать список всех лент (с ID и названием).
fetch	Обновить все ленты и показать новости (с учётом фильтров).
read	Прочитать новость по --id (открыть ссылку или показать текст).
filter	Установить фильтр (ключевые слова, дата, источник, статус).
save-filters	Сохранить текущие настройки фильтров в профиль.
load-filters	Загрузить фильтры из профиля.
export	Экспортировать подписки в OPML-файл (по умолчанию subscriptions.opml).
import	Импортировать подписки из OPML-файла (--file).
help	Показать справку.
Опции для фильтрации
Опция	Описание
--keyword <слово>	Фильтровать новости, содержащие ключевое слово (можно несколько).
--days <N>	Показывать новости только за последние N дней.
--source <название>	Фильтровать по названию источника (ленты).
--unread	Показывать только непрочитанные новости.
--read	Показывать только прочитанные новости.
--clear-filters	Очистить все фильтры.
Примеры
bash
# Добавить ленту
python rss.py add --url "https://example.com/feed" --title "Example News"

# Обновить и показать новости с фильтром по ключевому слову
python rss.py fetch --keyword "AI" --keyword "робот"

# Показать новости за последние 7 дней
python rss.py fetch --days 7

# Сохранить фильтры
python rss.py save-filters

# Загрузить фильтры и показать отфильтрованные новости
python rss.py load-filters && python rss.py fetch
Формат данных
Данные хранятся в JSON-файле (по умолчанию rss_data.json) со следующей структурой (расширенной для фильтров):

json
{
  "feeds": [
    {
      "id": 1,
      "title": "Example News",
      "url": "https://example.com/feed",
      "items": [
        {
          "id": 1,
          "title": "Article Title",
          "link": "https://example.com/article",
          "pubDate": "2025-01-01T12:00:00",
          "description": "Summary text...",
          "categories": ["tech", "AI"],
          "read": false
        }
      ],
      "last_fetch": "2025-01-01T12:00:00"
    }
  ],
  "next_feed_id": 2,
  "next_item_id": 2,
  "filters": {
    "keywords": ["AI", "робот"],
    "days": 7,
    "source": null,
    "unread_only": true
  }
}
Цветовая схема (тёмная тема)
Элемент	Цвет (ANSI)
Заголовок ленты	Ярко-голубой (96)
Название новости	Белый (97)
Дата	Серый (90)
Краткое описание	Жёлтый (93)
ID	Зелёный (92)
Ключевые слова	Пурпурный (95)
Ошибки	Красный (91)
Особенности реализаций
Все версии используют только стандартные библиотеки языка.

Парсинг RSS/Atom выполняется через встроенные XML-парсеры.

Данные хранятся в JSON (или эквивалентном формате).

Фильтрация реализована на уровне представления (не изменяет данные).

Сохранение фильтров в профиль (JSON).

Цветной вывод и поддержка тёмной темы.

Возможность открытия ссылок в браузере (через системную команду).
